# URB4N-APP — mises à jour Windows

Ce dépôt public contient les fichiers de distribution Windows et leurs manifestes SHA-256.
Le code de l’application et les configurations personnelles restent privés.

- [Télécharger la dernière version](https://github.com/realseb1502/urb4n-app-updates/releases/latest)
- [Site URB4N APP](https://urb4n-app.github.io/)
- [Confidentialité](https://urb4n-app.github.io/confidentialite.html)

À partir de la version 1.4.1, les fichiers sont nommés URB4N-APP.exe et URB4N-APP-Setup.exe,
avec leurs fichiers .sha256. Les utilisateurs d’une version antérieure doivent installer
une fois le nouvel installateur manuellement ; les versions suivantes utilisent les nouveaux noms.

Les archives « Source code » ajoutées automatiquement par GitHub contiennent seulement
les documents de ce dépôt public. Elles ne contiennent pas le code privé de l’application.
